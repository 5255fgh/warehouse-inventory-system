# 仓库盘点管理系统

一个面向仓库盘点、仓库文员、ERP/WMS 数据核对场景的纯前端盘点工具。支持 Excel 库存导入、扫码盘点、初盘与复盘、差异统计、进度备份、筛选检索和多工作表报表导出。

## 主要功能

- Excel/CSV 库存导入与工作表选择
- 商品编码、名称、系统数量、单价、库位、批次、单位字段映射
- USB/蓝牙扫码枪连续扫码盘点
- 扫码累加、减量纠错和扫码定位
- 重复编码按库位或批次选择
- 初盘、复盘和最终数量计算
- 盘盈、盘亏、未盘、无差异等筛选
- 批量确认无差异
- 差异原因快捷填写和批量应用
- 粘贴一列商品编码批量定位
- IndexedDB 自动保存
- JSON 进度备份与恢复
- 撤销与修改记录
- 差异报告、完整报告、多工作表 Excel 导出
- 异常商品打印清单
- 手机端卡片布局

## 使用方法

1. 下载本仓库，双击打开 `index.html`。
2. 点击“导入 Excel”，选择库存文件。
3. 选择工作表并确认字段映射。
4. 在初盘或复盘数量中录入数据，或开启持续扫码模式。
5. 完成后导出差异报告或完整盘点报告。

库存文件至少需要包含：

- 商品编码
- 商品名称
- 系统数量

单价、库位、批次和单位为可选字段。

## 扫码枪说明

普通 USB 或蓝牙扫码枪通常模拟键盘输入。建议将扫码枪设置为扫描后自动发送 Enter。程序会在持续扫码模式下自动清空输入框并等待下一次扫描。

## 数据与隐私

业务数据在浏览器本地处理，并通过 IndexedDB 自动保存。Excel 解析依赖 SheetJS CDN，因此首次使用和解析 Excel 时需要网络连接。建议定期导出 JSON 进度备份。
